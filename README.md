# Piolo Bagotao — Portfolio

Static portfolio adapted from the supplied September 2026 redesign.

Pages: index.html, about.html, case-study-ai-content.html, and case-study-customer-content.html.

Includes light/dark mode, saved theme preference, responsive layouts, seven brands, and three n8n workflow screenshots with full-size previews. Assets are bundled locally; Google Fonts loads the supplied fonts.

Deploy the contents of this folder to the repository root. No build step or package installation is needed. Vercel serves index.html as the homepage.
